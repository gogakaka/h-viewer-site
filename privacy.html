2. 기기에 저장되는 정보

테마·글자 크기 등 설정과 최근 문서 목록, 사용자가 허용한 파일·폴더의 접근 정보는 기기에 저장됩니다. 원본 문서는 수정하지 않습니다. 공유 확장에서 미리보기를 위해 만든 임시 문서 사본은 미리보기를 닫을 때 정리됩니다. 앱의 로컬 설정과 접근 정보는 기기에서 관리되며, 원본 문서와 별도로 저장됩니다. 원본 문서의 저장·삭제 및 iCloud 등 파일 제공자의 동기화는 해당 운영체제와 서비스에서 관리합니다.

사용자가 연 HTML에는 외부 이미지, 스크립트, 스타일 또는 네트워크 요청이 포함될 수 있습니다. Markdown에서도 외부 이미지를 표시할 수 있습니다. 이러한 리소스를 불러오면 사용자의 기기가 해당 외부 서버에 직접 연결하며, 서버에 IP 주소 등 통신 정보가 전달될 수 있습니다. 이는 문서가 지정한 외부 서비스의 개인정보처리방침에 따릅니다. 설정에서 HTML JavaScript 실행과 Markdown 외부 이미지 표시를 끌 수 있습니다. 외부 링크는 기본 브라우저 또는 해당 앱에서 열립니다.
