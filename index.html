Markdown 원문과 미리보기를 함께 읽고,
로컬 HTML의 인터랙션을 확인하세요.

문서 열기

  • 앱의 파일 열기에서 Markdown 또는 HTML 파일을 선택하세요.
  • iPhone·iPad에서는 파일 앱의 공유 → H Viewer로 문서나 선택한 일반 텍스트를 미리볼 수 있습니다.
  • Mac에서는 Finder의 다음으로 열기 → H Viewer 또는 드래그 앤 드롭을 사용하세요.
  • 별도 CSS·JavaScript·이미지가 있는 HTML은 본 앱에서 문서를 열고 리소스 폴더 연결로 해당 폴더를 선택하세요.

자주 묻는 질문

원본 문서가 바뀌나요?
아니요. H Viewer는 읽기 전용입니다. 다른 앱에서 수정한 내용은 새로고침해 확인하세요.

지원하는 파일은 무엇인가요?
.md, .markdown, .mdown, .mkd, .html, .htm 파일을 지원합니다. UTF-8 또는 BOM을 포함한 UTF-16 문서, 파일당 최대 20MB를 읽을 수 있습니다.

인터넷 연결이 필요한가요?
앱에 포함된 Markdown 렌더러는 오프라인에서 동작합니다. 문서의 외부 이미지·스크립트 등 웹 리소스를 불러오려면 인터넷 연결이 필요합니다.

HTML 기능이 일부 동작하지 않아요.
JavaScript 실행 설정과 리소스 폴더 연결을 확인하세요. 웹 서버가 필요한 모듈·fetch 등의 기능은 로컬 파일에서 제한될 수 있습니다. 공유 미리보기에는 함께 전달되지 않은 별도 리소스 파일이 포함되지 않습니다.
